# Licensing audit — 2026-10-14

Pinned iTerm2: `069b6e0dd8f3f0d82fc08ea5d294d28f7c5b986e` ([source](https://github.com/gnachman/iTerm2/tree/069b6e0dd8f3f0d82fc08ea5d294d28f7c5b986e)). Reviewed README, LICENSE, COPYING, README.license, ThirdParty/Licenses.txt, .gitmodules, selected terminal/session sources and headers.

README says GPLv3, LICENSE and README.license contain GPLv2. [COPYING](https://github.com/gnachman/iTerm2/blob/069b6e0dd8f3f0d82fc08ea5d294d28f7c5b986e/COPYING) explicitly says GPLv2-or-later and explains the full application is effectively GPLv3 because of Apache-2.0 dependencies. This supports electing GPLv3 for adapted covered components; the README and generic licence text alone do not settle the grant. Some source files have their own permissive notices, which must remain intact if copied. Do not assume every file has the same licence.

Aster-authored and iTerm2-adapted code is GPL-3.0-or-later. Preserve original attribution, identify adaptations and dates, include licence text, and distribute complete corresponding source/build scripts with binary releases. Do not imply official iTerm2 endorsement. The self-contained payload is reviewed by the source/notice inventory below; every package includes LICENSE, NOTICE, LICENSING, DEPENDENCY-SOURCES and the full licenses directory.

Restored-package inventory: `scripts/dependency-licenses.py` records all resolved versions from lockfiles. SkiaSharp and HarfBuzzSharp native package licence and third-party notices are retained under `licenses/`. Their broad notice collection includes BSD/MIT/Apache material, MPL/GPL/LGPL tri-licensed components, FreeType licence alternatives and LGPL/eCos material. It is not proof that every listed component is compiled into our payload. The pinned native build targets, external DEPS and licence alternatives have now been reviewed in [dependency-source-map.md](dependency-source-map.md). Optional microhttpd is absent from those targets; GPLv2-or-later is elected for tri-licensed material and FTL for FreeType where included. Do not infer native licensing from the NuGet MIT label alone. Embedded fonts remain OFL-1.1. Corresponding source URLs/build definitions and retained notices are listed in the source map and copied into the release.
